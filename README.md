# Robust and Explainable Multi-Class IoT Intrusion Detection Using Feature-Selected LightGBM

This repository provides the reproducibility package for the manuscript:

**Robust and Explainable Multi-Class IoT Intrusion Detection Using Feature-Selected LightGBM and Comparative Machine Learning–Deep Learning Models**

Submitted to: *International Journal of Intelligent Engineering and Systems (IJIES)*  
Paper ID: **20263169**

---

## 1. Purpose of This Repository

This repository contains the source code, preprocessing scripts, selected feature lists, model hyperparameters, random seeds, environment settings, result tables, and figures required to reproduce the experiments reported in the manuscript.

The repository is prepared to support reproducibility and transparency of the proposed IoT intrusion detection framework.

---

## 2. Dataset

This study uses the **CICIoT2023** dataset provided by the Canadian Institute for Cybersecurity.

The original dataset is **not redistributed** in this repository because it belongs to the dataset provider. Users should obtain the dataset from the official Canadian Institute for Cybersecurity source.
